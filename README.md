# pgotofood 📸

Фотографии блюд кофейни, обработанные в стиле профессиональной студийной фуд-фотографии.

## Структура

- `photo_*_2026-09-29_18-49-56.jpg` — оригинальные снимки (27 шт.)
- `IMG_8586.MOV`, `IMG_8628.MOV` — оригинальные видео
- **`studio/`** — основная серия: студийная съёмка на пастельно-оранжевом фактурном фоне
  - `photo_01_studio.jpg` … `photo_27_studio.jpg`
  - вид сверху (флэтлей) для тарелок и десертов, боковой ракурс для сэндвичей, чайника и слоёных напитков
  - мягкое студийное освещение, аккуратные тени, глянцевые аппетитные блики
- `edited/` — альтернативная осенняя серия (кленовые листья, тёплый грейд) + видео:
  - `photo_01_autumn.jpg` … `photo_27_autumn.jpg`
  - `IMG_8586_autumn.mp4`, `IMG_8628_autumn.mp4` — видео с осенней атмосферой: падающие листья, кино-грейд, авторская фоновая музыка
- `assets/` — рабочие материалы для видео (листья, музыка, скрипты ffmpeg)

## Стиль серии `studio/`

- Однородный пастельно-оранжевый фон с фактурой ручной штукатурки (как профессиональные фотофоны)
- Журнальное качество: мягкий рассеянный свет, деликатные тени под посудой
- Блюда и посуда сохранены в точности как на оригинальных снимках
