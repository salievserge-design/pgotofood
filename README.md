# pgotofood 🍁

Фотографии блюд кофейни, обработанные в стиле профессиональной студийной фуд-фотографии (осенняя тематика, глянцевый журнальный стиль).

## Структура

- `photo_*_2026-09-29_18-49-56.jpg` — оригинальные снимки (27 шт.)
- `IMG_8586.MOV`, `IMG_8628.MOV` — оригинальные видео
- **`edited/`** — обработанные материалы:
  - `photo_01_autumn.jpg` … `photo_27_autumn.jpg` — фото в осеннем глянцевом стиле (соцсети + меню)
  - `IMG_8586_autumn.mp4`, `IMG_8628_autumn.mp4` — видео с тёплой осенней цветокоррекцией

## Стиль обработки

- Тёплый осенний грейд: янтарь, карамель, багрянец
- Мягкий направленный студийный свет, кремовое боке
- Глянцевые аппетитные блики на еде («хочется съесть фотографию»)
- Осенний декор: кленовые листья, мини-тыквы, палочки корицы, гирлянды
- Видео: тёплая цветовая температура, насыщенность, мягкая виньетка, лёгкая резкость
