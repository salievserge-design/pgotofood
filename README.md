# pgotofood 📸

Фотографии блюд кофейни, обработанные в стиле профессиональной студийной фуд-фотографии.

## Структура

- `photo_*_2026-09-29_18-49-56.jpg` — оригинальные снимки (27 шт.)
- `IMG_8586.MOV`, `IMG_8628.MOV` — оригинальные видео

### `sunlight/duo/` — коллажи «блюдо + продукты» ☀️ (основная серия)
27 готовых коллажей `photo_01_duo.jpg` … `photo_27_duo.jpg` (2160×1350):
- один файл = две фотографии рядом: слева блюдо крупно (60%), справа hero-кадр ключевых продуктов (40%)
- стиль: тёплый кремово-бежевый фон, жёсткий солнечный свет, тени от оконной рамы
- также 11 коллажей по уникальным блюдам (`01_sandwich_duo.jpg` … `11_pumpkin_soup_duo.jpg`)
- `sunlight/pairs/` — исходные панели (отдельно блюда и продукты)

### `studio/` — студийная серия
27 фото на пастельно-оранжевом фактурном фоне (штукатурка), флэтлей где уместно, мягкий студийный свет.

### `edited/` — осенняя серия
27 фото в тёплом осеннем стиле + 2 видео (падающие листья, кино-грейд, авторская lo-fi музыка).

### `assets/` — рабочие материалы
Спрайты листьев, музыка, скрипты ffmpeg для видеообработки.
